# بناء ملف APK من GitHub (خطوة بخطوة)

## الفكرة باختصار

مجلد `android` ده تطبيق أندرويد حقيقي (Kotlin + WebView) بيفتح موقع HTML Maker جواه.
وملف `.github/workflows/build-apk.yml` هو اللي بيخلي GitHub يبني لك ملف الـ APK تلقائياً.

## الخطوات

### 1) انشر الموقع الأول (مهم جداً)

الـ APK بيفتح **رابط**، فلازم يكون عندك رابط شغال للموقع، زي:

- Vercel (الأسهل لـ Next.js)
- Render / Railway / أي استضافة

انسخ رابط موقعك، مثال: `https://html-maker.vercel.app`

### 2) ارفع المشروع على GitHub

ارفع **المشروع كله** (مش ملف واحد) على مستودع GitHub.
لازم الملف ده يكون موجود في المستودع:

```
.github/workflows/build-apk.yml
```

> ملحوظة: المجلدات اللي بتبدأ بنقطة (`.github`) أحياناً بتستخبى في مدير الملفات.
> لو بترفع من صفحة GitHub نفسها استخدم Add file ثم Create new file
> واكتب المسار كاملاً: `.github/workflows/build-apk.yml` والصق محتوى الملف.

### 3) شغّل البناء

1. افتح صفحة المستودع على GitHub من المتصفح.
2. دوس على تبويب **Actions** فوق.
3. هتلاقي Workflow اسمه **Build APK** على الشمال — دوس عليه.
4. دوس **Run workflow** ثم **Run workflow**.
5. استنى من 3 لـ 8 دقايق لحد ما العلامة تبقى خضرا ✅.

### 4) حمّل الـ APK

1. دوس على آخر عملية بناء ناجحة (الخضرا).
2. انزل تحت عند **Artifacts**.
3. حمّل `html-maker-apk`.
4. فك الضغط — جواه ملف `app-debug.apk`.
5. ابعته على موبايلك وثبّته (وافق على "التثبيت من مصادر غير معروفة" لو طلب).

### 5) أول تشغيل

- لو الرابط الافتراضي مش شغال، التطبيق هيعرض شاشة فيها زر **تغيير الرابط**.
- دوس على ⚙ أو زر تغيير الرابط والصق رابط موقعك المنشور.
- التطبيق بيحفظ الرابط، فمش هتحتاج تكتبه تاني.

## تغيير الرابط الافتراضي قبل البناء (اختياري)

عندك طريقتين:

**أ)** عدّل الملف `android/app/src/main/res/values/strings.xml` وسطر `start_url`.

**ب)** وانت بتدوس Run workflow اكتب الرابط في خانة `app_url`.

## ملاحظات

- الملف الناتج اسمه `app-debug.apk` — نسخة تجريبية (Debug) مناسبة للاستخدام الشخصي
  والتجربة، لكن **غير مناسبة للنشر على Google Play** (النشر يحتاج نسخة Release موقعة).
- التطبيق يحتاج إنترنت لأنه بيفتح موقعك المنشور.
- روابط ChatGPT و Claude و AI Studio بتتفتح في متصفح الموبايل تلقائياً.
